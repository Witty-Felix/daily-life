# 01 — Supabase 云端认证与敏感账户控制

**What to build:** 让被邀请的功过格用户能在 Supabase 云端安全进入和管理自己的账户：使用一次性恢复码或通行密钥登录，在刷新后恢复可信会话，管理已登录设备和恢复码；对生成恢复码、永久删除记录和删除账户等不可逆操作强制重新认证，并确保禁用或已删除账户不能再访问任何功过记录。

**Blocked by:** None — can start immediately.

**Status:** in-progress

- [ ] 恢复码登录、一次性失效、会话续存、设备撤销和“退出其他设备”可在真实云端完整验证。
- [ ] 通行密钥注册和登录在真实浏览器中通过服务端挑战、凭据归属和计数器校验；失败时不会创建会话。
- [x] 本地 SQLite 与 Edge Function 已加入一次性重新认证 proof、永久删除账户/记录保护和级联清理边界；真实 Supabase 认证链路仍需部署验收。
