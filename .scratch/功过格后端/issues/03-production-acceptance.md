# 03 — 生产验收与切换门槛

Type: task
Status: resolved
Blocked by: 01, 02

## Question

在开始实现和上线前，如何定义端到端验收标准：账户登录与数据隔离、功过记录增改删/修正、贪吃蛇最高分幂等更新、刷新与跨设备恢复、HTTPS、备份恢复和故障回滚？

## Answer

生产放行至少需要验证：账户 A/B 隔离；恢复码/Passkey 登录、会话撤销和敏感操作重新认证；功过记录 CRUD、历史修正、导出和迁移幂等；SQLite 完整性备份与恢复；HTTPS、Nginx 反代和 8787 不公网暴露；release 回滚；课间数据仍只在浏览器本地。若实施个人最高分，还需验证服务端只接受非负整数并以原子 `max` 更新，且没有跨账户读取或排行榜接口。

验证：由前两个研究节点的结论合并形成；真实生产验收尚未执行。
