# 04 — 贪吃蛇课间游戏

**What to build:** 用户抽到贪吃蛇后，可以进入内置小游戏，在 3 张预设地图中进行最多 3 局游戏；游戏支持电脑和手机操作、暂停、边界穿越、方块障碍、食物和计分，并正确计入本次课间局数。

**Blocked by:** 01 — 核心课间流程与加权抽取

**Status:** completed

- [x] 提供 3 张经过验证且可玩的预设地图，每局随机选择一张
- [x] 地图约 20×20 格，边界可穿越，方块不可穿过
- [x] 撞到方块或自身时结束本局
- [x] 食物只生成在可通行且不被蛇身占用的位置
- [x] 蛇以 3 格长度开始，初始方向保证第一步可行
- [x] 每吃一个食物得 1 分并增长一格
- [x] 支持方向键、WASD、手机滑动、暂停和主动结束
- [x] 点击暂停或页面失去焦点时自动暂停
- [x] 每次课间最多开始 3 局；开始即计数，刷新或中断也计数
- [x] 达到 3/3 后禁用开始游戏，但仍可返回活动卡片并确认完成
- [x] 至少开始并结束 1 局后，用户可以自行确认活动完成
- [ ] 通过电脑和手机的真实浏览器行为验证游戏规则
