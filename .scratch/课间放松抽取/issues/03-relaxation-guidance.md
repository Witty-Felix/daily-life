# 03 — 放松建议与戒色练习选择

**What to build:** 每种放松方式都有明确的行动建议和预计时长；抽到“戒色练习”后，用户可以从 6 个子活动中选择一个，并能在不消耗主抽取次数的情况下重新选择。

**Blocked by:** 01 — 核心课间流程与加权抽取

**Status:** completed

- [x] 喝水、散步、看书、唱歌、打球和贪吃蛇展示固定行动建议及预计时长
- [x] 戒色练习展示 6 个可选择子活动
- [x] 子活动包含内置提示文字、阅读自备文章、听或观看自选内容、俯卧撑、固肾功、自我反思或呼吸练习
- [x] 用户选择子活动后可以返回重新选择
- [x] 重新选择子活动不消耗主抽取的换一个次数，也不产生新的抽取
- [x] 不展示色情内容，不提供医疗承诺，不依赖外部内容链接
- [x] 通过真实浏览器行为验证活动建议和子活动选择
