# 01 — 核心课间流程与加权抽取

**What to build:** 用户可以打开网站，点击“开始本次课间”，系统立即创建课间并按预设权重抽取一个放松方式，展示当前放松建议；用户可以确认完成或结束课间，刷新页面后能够恢复进行中的课间。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 空闲首页提供开始本次课间入口，并能创建唯一的进行中课间
- [x] 开始课间后自动抽取一种放松方式，权重为 18 / 18 / 15 / 15 / 11 / 11 / 11
- [x] 一次课间只能产生一次正式抽取结果
- [x] 进行中页面展示当前放松方式、行动建议、预计时长、完成和结束课间操作
- [x] 完成与结束课间相互独立；未完成结束会保留未完成记录
- [x] 同一时间不能存在多个进行中的课间
- [x] 课间状态和记录保存在浏览器本地，刷新或重新打开后可恢复
- [x] 通过真实浏览器行为验证核心流程和本地恢复
